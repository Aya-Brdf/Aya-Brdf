## 🚀 Featured Projects

### 1. [Deepfake Detection System](https://github.com/Aya-Brdf/deepfake-detection-system)

A deep-learning application exploring the detection of manipulated and AI-generated images and videos. It combines computer-vision experiments with a web interface and a Python backend.

**Focus:** Computer Vision · Image Classification · Model Comparison · Explainability  
**Technologies:** Python, PyTorch, EfficientNet-B0, scikit-learn, OpenCV, FastAPI/Flask, React/Next.js

### 2. [SentimentLens — Real-Time Amazon Reviews Analysis](https://github.com/Aya-Brdf/amazon-reviews-analysis)

A Big Data and machine-learning pipeline for classifying Amazon customer reviews as positive, neutral, or negative. The project includes text preprocessing, model evaluation, batch analysis, streaming, storage, and a dashboard.

**Focus:** NLP · Sentiment Analysis · Distributed Processing · Real-Time Data  
**Technologies:** Apache Spark / PySpark MLlib, Kafka, MongoDB, Flask, Airflow, Docker

### 3. Water-Quality Monitoring Dashboard — CIRQUA / PRIMA

Academic project carried out with a scientific group at the Faculty of Sciences and Techniques of Tangier, in the context of the international CIRQUA project and collaboration with CIIMAR in Portugal. The work includes a dashboard for exploring sensor measurements, filtering time ranges, comparing data series, and contributing to monitoring and alert workflows.

**Focus:** Environmental Data · Monitoring · Time-Series Visualization · API Integration  
**Technologies:** Python, FastAPI, Next.js, WebSockets, PostgreSQL, data visualization

### 4. [NLP Practice Notebooks](https://github.com/Aya-Brdf/Notebooks_NLP)

A collection of notebooks for experimenting with natural-language-processing concepts and workflows.

**Focus:** NLP · Text Processing · Experimentation  
**Technologies:** Python, Jupyter Notebook

### 5. [Business Intelligence Projects](https://github.com/Aya-Brdf/BI)

A space for business-intelligence and data-visualization work.

**Focus:** Data Analysis · Reporting · Visualization  
**Technologies:** BI tools and data analysis
